Anthropic Claude for Copilot Chat uses your own Anthropic API key to make Fable 5.1, Opus 5, and Sonnet 5 available in the model picker.

Paste it once, then update or remove it later from the Command Palette.

- `Cmd/Ctrl + Shift + P`: Open the Command Palette
- `Anthropic: Set API Key`: Set or update your API key
- `Anthropic: Clear API Key`: Remove your API key
- `Anthropic: Get API Key`: Create an Anthropic API key
